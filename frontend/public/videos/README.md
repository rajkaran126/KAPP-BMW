# Hero Video

Place your BMW hero video here as `hero.mp4` or `hero.webm`.

The video will be displayed as the background of the hero section on the home page.

## Recommended specs:
- Format: MP4 (H.264) or WebM
- Resolution: 1920x1080 or higher
- Duration: 10-60 seconds (looped)
- Keep file size under 50MB for fast loading

If no video is found, the hero section will display a beautiful gradient fallback automatically.
