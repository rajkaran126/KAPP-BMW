# BMW Car Images

Place your BMW car images in this folder with the following naming convention:

## Naming Format:
```
[model-name].jpg  or  [model-name].png
```

## Required Images:
- `bmw-m5.jpg` - BMW M5
- `bmw-x5.jpg` - BMW X5
- `bmw-x7.jpg` - BMW X7
- `bmw-m3.jpg` - BMW M3
- `bmw-ix.jpg` - BMW iX
- `bmw-i4.jpg` - BMW i4
- `bmw-7-series.jpg` - BMW 7 Series
- `bmw-3-series.jpg` - BMW 3 Series
- `bmw-x3.jpg` - BMW X3

## Image Specifications:
- **Format:** JPG or PNG
- **Recommended Size:** 800x600px or 1200x800px
- **Aspect Ratio:** 4:3 or 16:9
- **File Size:** Keep under 500KB for performance

## Where to Get Images:
1. **Official BMW Website:** https://www.bmw.com
2. **Stock Photo Sites:** Unsplash, Pexels (search "BMW [model]")
3. **CarDekho:** https://www.cardekho.com/bmw-cars

## Example:
```
frontend/public/images/cars/
  ├── bmw-m5.jpg
  ├── bmw-x5.jpg
  ├── bmw-x7.jpg
  └── ... (add more)
```

After adding images, the app will automatically load them!
